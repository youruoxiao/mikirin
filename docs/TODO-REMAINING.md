## 推荐执行顺序与项目收口

1. 使用现有命令在旁路库产出检索/图谱对照与审核文件，保持人工标签为空。
2. 完成检索、记忆、黑话、关系的人工验收；不达标则修正数据、阈值或模型。
3. 在真实规模上测季度增量恢复与运行时间，存档配置和报告。
4. 确认发布门禁后再切换正式库；数据库上传另需明确目标仓库及再分发范围。

当 P0 全部完成时，项目已经具备可发布的核心闭环；P1/P2 是路线图承诺的扩展能力。只有 P0、P1、P2 全部勾选且各自验收产物已存档，才算 `SPEC-ROADMAP.md` 当前范围整体完结。
